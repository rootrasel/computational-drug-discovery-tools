# DeepChem Drug Discovery Curriculum

This directory contains a structured learning curriculum for utilizing **DeepChem** in the context of AI-driven drug discovery. The notebooks are designed to guide you progressively from foundational concepts to advanced predictive modeling.

## Curriculum Structure

- **01_DeepChem_Introduction_and_Setup.ipynb**: Getting started with DeepChem, environment setup, and basic concepts.
- **02_Molecular_Featurization.ipynb**: Converting chemical structures into machine learning-readable formats (e.g., ECFP, Graph convolutions).
- **03_Datasets_and_Data_Loading.ipynb**: Handling standard drug discovery datasets (MoleculeNet) and loading custom data.
- **04_Molecular_Property_Prediction.ipynb**: Building initial models to predict molecular properties (e.g., solubility).
- **05_GNN_Molecular_Representation.ipynb**: Leveraging Graph Neural Networks (GNNs) for deep molecular representations.
- **06_Toxicity_Prediction_Model.ipynb**: Case study on predicting chemical toxicity (e.g., Tox21 dataset).
- **07_Bioactivity_and_QSAR_Modeling.ipynb**: Quantitative Structure-Activity Relationship (QSAR) modeling for bioactivity.
- **08_Binding_Affinity_Prediction.ipynb**: Predicting protein-ligand binding affinities.
- **09_AI_Drug_Discovery_Pipeline.ipynb**: Assembling a complete end-to-end drug discovery pipeline.
- **10_Model_Evaluation_and_Interpretability.ipynb**: Evaluating model performance and interpreting ML decisions in chemistry.

## Setup Instructions

To run these notebooks, ensure you have your conda/python environment configured with DeepChem and Jupyter.

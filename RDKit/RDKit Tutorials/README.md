## 🏆 Production Capstone Projects

* [**Capstone Project 01: End-to-End Virtual Screening & Drug-Likeness Discovery Pipeline**](file:///home/softvence/Projects/AI-Engineer-for-Life-Sciences-Libraries/Cheminformatics/RDKit/RDKit%20Tutorials/16_End_to_End_Drug_Discovery_Project/Project_01_End_to_End_Virtual_Screening_Pipeline.ipynb)  
  *Automated 7-stage screening cascade: Library ingestion, salt stripping, Lipinski/Veber drug-likeness, PAINS/Brenk toxicophore filters, hinge-binding pharmacophore matching, Morgan ECFP4 Tanimoto similarity to Gefitinib, multi-parametric optimization (MPO), and annotated SDF export.*

* [**Capstone Project 02: Production Machine Learning QSAR & Chemical Space Explorer**](file:///home/softvence/Projects/AI-Engineer-for-Life-Sciences-Libraries/Cheminformatics/RDKit/RDKit%20Tutorials/16_End_to_End_Drug_Discovery_Project/Project_02_Machine_Learning_QSAR_and_Chemical_Space_Explorer.ipynb)  
  *End-to-end predictive machine learning on 4,772 real ChEMBL EGFR compounds: InChIKey deduplication, hybrid ECFP4 + 2D descriptor featurization, Bemis-Murcko scaffold splitting, Random Forest & Gradient Boosting benchmarking, t-SNE chemical space mapping, and prospective virtual screening.*
